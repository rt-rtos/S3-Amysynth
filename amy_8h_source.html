455// LOCAL EDIT (S3-Amysynth): do NOT zero .start here. The dump (and thus this
456// reset) runs on Core 0 while render START/STOP run on Core 1. Zeroing .start
457// between a START and STOP made the STOP compute (now - 0) ≈ uptime, producing
458// per-window spikes of ~uptime µs on whichever tag was mid-flight. .start is
459// only ever read by a STOP that always follows a START, so it never needs
460// zeroing; leaving it makes a racing STOP yield a normal-sized sample. See
461// AMY-EDITS.md / docs/AMY-PROFILE-LOG.md.
462#define AMY_PROFILE_INIT(tag) \
463 profiles[tag].calls = 0; \
464 profiles[tag].us_total = 0; \
