1/* bass_presets.c - three two-oscillator bass presets for melodic layers.
2 *
3 * Patch IDs 264-266 (SEQ_PATCH_BASS_1/2/3), dispatched from
4 * sequencer_configure_synth() when is_bass_patch is true.
5 *
6 * All AMY interaction goes through the queued event API - never direct synth[]
7 * access. These run from synth_ui_task (Core 0), outside the render body
8 * (amy_render lock rules: AMY-EDITS.md).
9 *
10 * filter_freq_coefs[]: COEF_CONST is in Hz; non-CONST coefs are dimensionless
11 * logfreq-delta weights in octaves (COEF_EG1 = 4.06 sweeps 120 Hz -> ~2000 Hz
12 * at EG1 peak).
13 *
14 * freq_coefs[COEF_CONST] is also Hz, stored by AMY as log2(f/ZERO_LOGFREQ_IN_HZ)
15 * and added to the note term - so ZERO_LOGFREQ_IN_HZ * r is a note-tracking
16 * pitch offset of log2(r) octaves. `ratio` is not that: AMY reads logratio
17 * only in render_fm_sine, so on a non-ALGO osc it is a no-op.
18 *
19 * BASS_1/BASS_2 route the filter sweep through EG1, separate from the amp
20 * envelope (EG0): plucky amp decay over a slower-settling filter tail. Each
21 * EG1 breakpoint set is pushed in the SAME event as the coef reading it - an
22 * unconfigured breakpoint set reads as a permanent 1.0 gate in AMY and would
23 * pin the sweep fully open. BASS_3 has no filter section. */
24
