2// Per-core busy-percentage sampler from idle-hook invocation counting.
3// Each core's IDLE task calls a registered hook every idle-loop iteration;
4// counting invocations per wall-clock window yields an idle rate, and busy
5// is that rate measured against the highest rate ever observed on the core
6// (a self-calibrating "fully idle" reference). The hook body is one counter
7// increment - no locks, no kernel API, no critical sections. ISR time is
8// captured naturally: interrupts steal cycles from the idle loop, lowering
9// the observed rate.
10//
11// This replaced a uxTaskGetSystemState()-based sampler deliberately: that
12// call walks every TCB inside the kernel critical section with interrupts
13// masked on the calling core, and its occasional multi-ms walks under cache
14// pressure blocked the USB interrupt's isochronous endpoint re-arm -
15// audible as 1-2 ms holes in the UAC stream on the sampler's exact 1 s
16// grid (root-caused 2026-08-13; see UAC-EDITS.md). Any future
17// reimplementation must not take kernel critical sections on a periodic
18// grid.
19//
20// Obligations: call core_load_sample() from a single task only (static
21// delta state, no locking); never from an ISR. Keep the call interval
22// >= ~100 ms so idle-rate noise averages out.
23//
24// Guarantees: returns true with busy_pct[core] = 0..100, the average busy
25// share of each core since the previous successful call - band-indicator
26// grade (roughly +-10-20%), biased LOW until the core has had at least one
27// mostly-idle window since boot to calibrate against. Returns false with
28// busy_pct untouched on the first call (baseline capture + hook
29// registration) or if hook registration fails; the next successful call
30// averages over the whole gap. Wrap-safe across one counter wrap.
