11/* ── Arp screen renderer ──────────────────────────────────────────────────
12 * Like the menu, the arp logic lives in the synth_core component (arp_core).
13 * synth_ui populates this flat view each frame; the renderer just draws it.
14 *
15 * Layout (everything visible at once — no multiplexed slots):
16 * ARP:ON | MODE | OCT:2 | R:1/16 <- macro row 1 (cursor 0..3, L→R)
17 * GATE:75% | W:SAW/P12 | GL:200 <- macro row 2 (cursor 4..7, L→R)
18 * [C3] E3 G3 B3 -- -- ... <- 8 note slots
19 *
20 * Cursor index space:
21 * 0=ARP enable, 1=MODE, 2=OCT, 3=RATE, 4=GATE,
22 * 5=SOURCE, 6=WAVE (skipped in PATCH mode), 7=GLIDE, 8..15 = slots 0..7.
23 *
24 * The row-2 centre indicator shows the source implicitly (W: = wave engine,
25 * P = patch); on the SOURCE cursor it reads SRC:W / SRC:P. GLIDE (portamento)
26 * now has its own permanent right-aligned readout rather than borrowing the
27 * indicator slot, so no field is hidden behind the cursor position. */
