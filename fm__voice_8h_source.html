9/* ── Generic 6-operator DX7-style FM/ALGO voice engine ───────────────────────
10 * Wraps AMY's ALGO wave type (amy.h ALGORITHM/algo_source[], algorithms.c's
11 * 33 fixed 6-operator routing tables) as a single melodic "voice": one AMY
12 * ALGO control osc (osc 0, relative) plus six SINE operator oscs (osc 1..6,
13 * relative), so oscs_per_voice is always 7 regardless of which algorithm is
14 * selected — every one of AMY's 33 algorithms wires all 6 operator slots, so
15 * this fixed layout is correct-by-construction for any algorithm index; no
16 * per-algorithm special-casing is needed here.
17 *
18 * Array index -> AMY algo_source[] slot -> relative osc:
19 * op_ratio[i]/op_level[i] <-> algo_source[i] <-> osc (i + 1)
20 * algorithms.c authors slot 0 as DX7 "operator 6" and slot 5 as "operator 1"
21 * (transcribed from the MFSA DX7 tables); this engine does not renumber that,
22 * so cross-referencing a real DX7 algorithm chart means reading slot 5 as
23 * OP1, slot 4 as OP2, etc. The UI screen labels rows by array index (OP 0..5)
24 * to keep the mapping obvious in code; relabeling to DX7 numbering is a
25 * cosmetic follow-up (see docs/handoff).
26 *
27 * Per-operator "level" is that operator's own amp_coefs[COEF_CONST] — for an
28 * operator that writes to a modulation bus this is literally the FM
29 * modulation index/brightness; for an operator that is a final carrier
30 * (writes directly to the voice output) it multiplies the shared voice
31 * envelope on osc 0. Setting an operator's level to 0 silences it (and, for
32 * a modulator, degrades whatever it fed into a plain unmodulated tone) —
33 * exactly like a real DX7's operator output level knob, and the mechanism
34 * this engine relies on to let presets use fewer than 6 audible partials
35 * without needing per-algorithm routing knowledge.
36 *
37 * All 6 operators share ONE amplitude envelope (osc 0's own eg0, driven by
38 * the row's existing per-track ADSR editor — see seq_core_editors.c) plus a
39 * fixed short default envelope baked in at configure time for the operators
40 * themselves. Genuine DX7 patches give every operator its own independent
41 * envelope; that is out of scope for this vertical slice (see docs/handoff
42 * for the deferred work list). */
43
