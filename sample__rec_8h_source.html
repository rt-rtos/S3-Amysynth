10/* ── Runtime PCM sampler ("record into a one-shot pad") ──────────────────
11 * Captures AMY's own final mixed output into a single runtime PCM preset
12 * slot, then wires that preset into one drum-layer track so it plays back
13 * exactly like the built-in 808 samples (render_pcm, note-on/off, the
14 * per-track PCM envelope). Fixed-length mono buffer, one slot — a vertical
15 * slice, not a multi-slot looper (see docs/handoff/pcm-sampling.md for the
16 * extension path and why audio-in capture was deferred).
17 *
18 * Flow, driven from the menu overlay's "Sample" item:
19 * IDLE --arm--> ARMED --start--> RECORDING --(auto, fixed length)--> READY --assign--> IDLE
20 * CANCEL aborts from ARMED/RECORDING/READY back to IDLE and frees the slot.
21 *
22 * ARM pre-allocates the PCM buffer (via pcm_load) up front so START never
23 * allocates; START just flips a flag the render task observes at the next
24 * block boundary, so capture always begins exactly on a block edge. */
25typedef enum {
26 SAMPLE_REC_IDLE = 0,
27 SAMPLE_REC_ARMED,
28 SAMPLE_REC_RECORDING,
29 SAMPLE_REC_READY,
30} sample_rec_state_t;
